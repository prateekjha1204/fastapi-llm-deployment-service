# Full-Stack Quantized LLM Inference Service

An end-to-end full-stack AI application featuring an asynchronous **FastAPI** backend for quantized local model inference and a responsive **React** user interface.

## 🏗️ Architecture

- **Frontend:** React.js, JavaScript (ES6+), CSS3.
- **Backend:** FastAPI, Uvicorn, Pydantic data validation.
- **Containerization:** Docker container runtime.

## ✨ Features

- **Real-Time Interactive UI:** Clean React interface to submit prompts and stream inference responses.
- **High-Throughput Serving:** Low-latency RESTful API handling prompt processing.
- **Production Ready:** Dockerized service setup for scalable cloud deployment.

## 🚀 How to Run

### 1. Backend Service

```bash
pip install -r requirements.txt
python main.py
```

### 2. Frontend Application

```bash
cd frontend
npm install
npm start
```
